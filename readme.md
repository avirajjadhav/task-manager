Task Manager

A simple and responsive Task Manager built using HTML, CSS, and Vanilla JavaScript. This project was created to practice DOM manipulation, events, arrays, objects, and browser LocalStorage.

🚀 Features
➕ Add new tasks
🏷️ Assign categories to tasks
✏️ Edit existing tasks
🗑️ Delete tasks
✅ Mark tasks as completed
💾 Save tasks using LocalStorage
📱 Responsive design for mobile and desktop
🎨 Clean and colorful UI
🛠️ Technologies Used
HTML5 — Structure
CSS3 — Styling and responsive design
JavaScript — Functionality and DOM manipulation
LocalStorage — Persistent task data
